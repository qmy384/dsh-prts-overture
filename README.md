# PRTS 启动序列

一个用于 DeepSeek Harness Web UI 的中文启动界面：以 PRTS 终端恢复「前文明档案」为叙事，操作员身份是**预言家 / 博士**。界面文字为中文，关键台词由英文女声播报；整体配色以黑、白、灰为主；只有普瑞赛斯的「记忆异常」段落会出现红色错误弹窗。

## 六幕流程

1. **冷启动** — PRTS 核心在线、罗德岛链路稳定、前文明档案封存、石棺信号、记忆完整度 3.7%。
2. **档案层** — PRTS 终端徽记展开，显示前文明档案需要重建。
3. **神经握手** — 按住核心约 1.5 秒（或按住 `空格` / `回车`）建立神经链接；松开会提示「接触中断」。
4. **记忆回收** — 三选一：`源石`、`普瑞赛斯`、`石棺`。选择页默认保持原来的三张卡片，只有把鼠标移到普瑞赛斯卡片上（或键盘聚焦）时，才会淡入她的 CG 肖像；移开就消失。选中后，先出现约 2.3 秒的正常碎片结果和她的肖像，随后突然报错：红色错误弹窗会自动增多；`确定` / `×` 只是可选的沉浸互动，关掉一个会再冒出更多，但**不影响中央拼字**。中央「不许忘记我」会随倒计时自动显现，而且五字出现得越来越快（出现时间点约 0.2 / 1.4 / 2.3 / 2.9 / 3.3 秒，相邻间隔 1.2 / 0.9 / 0.6 / 0.4 秒，指数级缩短）；第五个「我」出现后约 0.05 秒，会立刻低声说 “Do not forget me.”，5 秒到点，剩余弹窗一起收束。错误窗的位置、角度、宽度和自动冒出的节奏每次播放都随机，只避开中央五个字。
5. **身份档案** — 确认「预言家 / 博士」，显示出身、职责、权限、合作者、最后接触等档案字段。
6. **终幕身份纠正** — 先显示「欢迎回家，博士」，英文女声说 “Welcome home, Doctor.”；随即电流杂音，名字被强改为「预言家」，女声冷声说 “Prophet.”。在改名完成前，每点一次「进入现在」/回车，右侧就多一个位置、角度和宽度都随机歪斜的系统错误窗，同时**叠加**一句独立的英文错误 “Error. Identity rewrite in progress.” 和一层错误音效；点几次就叠几个、响几次，不遮挡中央改名。变化语音保持本环节最大音量（1.0），不会被错误音效切断；错误语音和音效各自独立、互不打断，但音量压得很低（错误语音约 0.12，主语音播放时再减半；最多 2 层），点很多下也不会盖过变化人称。名字一变，所有错误窗碎成白色碎片飞向中央。若没有提前点，改名和 Prophet 播报结束后会说一句 “Thank you, Prophet.”（界面显示「谢谢你，预言家。」）再进入系统；若提前点过，则播报结束后直接进入。原来的自动继续进度条已移除。

右上角始终有「跳过 [ESC]」，`Esc` 随时退出。声音按钮可一键静音／取消静音。

## 中文界面 + 英文女声

- 所有界面文案、按钮、日志、档案字段和设置页均为中文。
- 关键台词由 `en-GB-SoniaNeural` 英文女声念出，音频随插件打包，不依赖在线 TTS；新增 `priestess`、`forget`、`welcome_doctor`、`welcome_prophet`、`error_rewrite`、`thank_you_prophet` 六句。
- 呼号可以改，但预生成的英文女声固定念 `Prophet` / `Doctor`；如果希望语音跟随新呼号，需要用 `scripts/generate-voice.py` 重新生成。
- 如果浏览器不允许自动播放，首次点击／按键后会解锁音频；被拦下的台词会在 7 秒内补播。
- 如果打包音频不可用，会回落到浏览器 Web Speech API，并优先选择英文女声。
- 设置页可单独关闭「英文女声播报」或「界面音效」。
- 整段约 30–40 秒（含普瑞赛斯分支的互动倒计时；不选择该分支会更短）；默认每次页面加载播放，可在设置中改为每个标签页一次。

## 视觉

- 主色：黑 `#050505`、白 `#f2f2f2`、灰阶 `#d6d6d6` / `#a3a3a3` / `#666666`。红色 `#ff2b2b` 只存在于普瑞赛斯的记忆异常弹窗和「不许忘记我」大字。
- 强调方式：只用亮白和浅灰，通过亮度、线宽、虚线和字重建立层级；握手环、状态点用亮白，其余标签和辅助线用灰。
- 背景由 Canvas 尘埃、蓝图网格、等高线环、半调网点、标尺刻度、扫描线、噪点、暗角和页脚条码组成；除异常段外没有彩色。
- 身份档案卡使用原创的匿名剪影 + 指纹 + 条码叠层，做出「被涂黑的技术档案」质感；全部为 CSS/SVG，不依赖外部图片。
- 报错弹窗：普瑞赛斯段和终幕段的窗口位置、倾斜角、宽度、出现节奏都随机化，每次播放不一样；只避开中央的关键信息。
- 动势：0.42 秒横向裁切转场、徽记彗星弧、握手轨道/脉冲、链接冲击环、背景极慢漂移；不使用弹跳和频繁闪烁。
- 普瑞赛斯异常段：红色错误弹窗自动增殖、五字按时间加速显现、5 秒倒计时；剩余弹窗在结尾收束成「不许忘记我」大字。红色只在这里出现。
- 普瑞赛斯形象：选择页的普瑞赛斯卡只在悬停/聚焦时显示肖像；正常结果页、异常段背景使用同一张 CG 裁剪。全部强制灰度，红色只留给异常段的错误弹窗和「不许忘记我」。
- 终幕：博士 → 电流杂音 → 预言家，名字用裁切/错位闪切完成覆写。
- 尊重 `prefers-reduced-motion`：减少动态时关闭故障抖动和常驻粒子动画。

## 设置

打开 **设置 → PRTS 启动**：

- 显示／关闭启动序列。
- 播放时机：每次页面加载（默认）、每个标签页一次、每天一次。
- 序列速度 0.5×–2×。为了保证英文台词完整，关键阶段的时长有最低值。
- **全屏**：右上角「全屏 / 退出全屏」手动切换；启动时不会自动请求全屏。
- **英文女声播报** 与 **界面音效** 分别开关。
- 呼号（默认「预言家」）、身份后缀（默认「博士」）。
- 是否显示完整对象档案。
- **预览序列**：关闭设置并立即重播，不消耗「本次已播放」标记。
- **恢复默认**。

设置保存在 `localStorage` 的 `dsh-prts-startup:config:v1`。

## 全屏

- 启动遮罩始终是 `position: fixed; inset: 0; width: 100vw; height: 100dvh`，不依赖设置，保证铺满浏览器视口。
- **主窗口不会自动全屏**：插件不会在页面加载或启动动画期间调用 `requestFullscreen()`；只有右上角「全屏 / 退出全屏」按钮会手动切换。
- 独立全屏窗口：本仓库只包含客户端启动序列，不包含宿主侧 overlay 实验。当前 DSH Host 运行在 Node host 进程（`process.type` 为 `undefined`；`require('electron')` 不可用，只有 `process.versions.electron`），无法创建 Electron `BrowserWindow`；因此启动动画在主窗口内铺满，主窗口原始大小/全屏状态保持不变。若后续宿主暴露窗口 API，可再接独立窗口。
- 浏览器全屏限制：手动按钮也需要用户手势；iframe 未授权、浏览器策略或 Electron 宿主限制时可能被拒绝。被拒绝时遮罩仍然铺满视口，只是浏览器/系统边框还在。插件无法绕过这个限制，也不能直接强制操作系统窗口全屏；`Esc` 通常先退出全屏，再按一次或点「跳过」结束动画。

## 音效与语音来源

- 12 个音效来自 Freesound 的 **CC0 1.0** 素材（终端提示、扫描、伺服、故障、冲击、断电、数据流、确认、错误、静电、电击等）。完整作者与链接见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

- 普瑞赛斯肖像裁剪自《明日方舟》官方 CG，转为灰度 WebP 内联进 bundle；仅用于非商业同人展示，版权归 Hypergryph；如权利人要求，会移除 `assets/art/priestess.webp` 及构建产物中的对应图像。

## 构建

`client.js` 是生成产物，CSS、音频和插画都以字符串形式内联，避免额外路由和素材加载：

```bash
node scripts/build.mjs
node --check client.js
```

目录：

```
prts-startup/
├─ package.json
├─ cordis.patch.yml
├─ index.js                  Host 半侧（无服务端状态）
├─ client.js                 生成后的 Client bundle（含 CSS、音频与插画）
├─ icon.svg                  黑/白/灰图标
├─ locale/en.json
├─ locale/zh.json
├─ src/client.source.js      可读源码
├─ src/client.css            原创视觉系统
├─ scripts/build.mjs         内联 CSS、音频与插画
├─ scripts/generate-voice.py 重新生成英文女声
├─ assets/voice/*.mp3        14 句英文女声
├─ assets/sfx/*.mp3          12 个 CC0 音效
├─ assets/art/priestess.webp 普瑞赛斯肖像（官方 CG 裁剪）
├─ assets/sfx-manifest.json  音效元数据
└─ THIRD-PARTY-NOTICES.md
```

## 安装

这是一个本地 DSH 插件，不通过 npm 发布。以 `desktop` profile 为例：

1. 把仓库克隆或下载到任意目录。
2. 在 `~/.dsh/profiles/desktop/package.json` 的 `dependencies` 中加入：
   ```json
   "dsh-prts-startup": "link:D:/path/to/prts-startup"
   ```
   并把 `"dsh-prts-startup"` 加入 `dsh.profile.bundles`。
3. 在仓库目录运行 `node scripts/build.mjs`（修改 `src/` 后需要；仓库已带构建好的 `client.js`）。
4. 刷新 DSH 页面；如果客户端模块被缓存，重新打开应用或再刷新一次。
5. 若你的 DSH 版本支持 `dsh plugin --profile desktop install`，也可以在完成依赖声明后用它安装本地 bundle。

修改 `client.js` 后刷新页面即可加载新版本；`client.js` 是生成产物，不要手改。
