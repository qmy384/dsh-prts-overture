## English female narration

The fourteen English lines under `assets/voice/` were generated for this plugin with
**Microsoft Edge neural TTS**, voices `en-GB-SoniaNeural` (regular) and
`en-US-AvaNeural` (the special “Do not forget me.” line), using the script
`scripts/generate-voice.py`. They are not recordings from Arknights or any other
game. The browser's Web Speech API is used only as a fallback when the bundled
MP3s cannot be played.
